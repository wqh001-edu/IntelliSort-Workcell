# 13 · HTML 演示与学习系统

## 定位

产品官网 × 技术文档 × 答辩系统 × 数字孪生展示 × 个人复习站

## 入口

仓库根目录 [`index.html`](../index.html)（纯静态，双击可开）

## 信息架构

- 首页：名称、场景、技术栈、指标  
- 一级模块：总览/场景/架构/ROS2/机械臂/感知/规划/抓取/任务/仿真/硬件/实验/异常/进度/Demo  
- 三级下钻：目标检测、位姿估计、OMPL、行为树等  
- 每页学习卡片：这是什么 / 为什么 / 输入输出 / ROS2 实现 / 代码位置 / 如何运行 / 如何验证  

## 技术

- `index.html` + `css/styles.css` + `js/data.js` + `js/app.js`  
- hash 路由，无构建  
- 深色工程风，卡片 + 侧栏 + 面包屑
