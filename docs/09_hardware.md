# 09 · 硬件设计与迁移

## 三档方案

| 档位 | 预算 | 配置 |
|------|------|------|
| 入门 | ¥0.6–1.2万 | 仿真 + 可选 myCobot / USB 相机 |
| **推荐** | ¥6–12万 | xArm6 + 电动夹爪 + D435 + 工控机 |
| 高配 | ¥18–35万 | xArm7/UR5e + D455 + 力控预留 + 安全围栏 |

## 迁移检查单

1. `use_sim_time:=false`  
2. `robot_driver:=xarm`，安装 `xarm_ros2`  
3. 相机换成 `realsense2_camera`  
4. 手眼标定 → 更新 TF  
5. 降低速度缩放（0.2–0.3）  
6. 急停与软限位  
7. 先空跑，再抓取
