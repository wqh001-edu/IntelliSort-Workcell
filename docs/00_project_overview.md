# 00 · 项目总览

## 名称

- 中文：**智拣柔性工作站**
- 英文：**IntelliSort Workcell**
- 代号：`ISC-1`

## 一句话

视觉引导六轴机械臂完成多品种零件识别、抓取、分拣与上下料，具备异常恢复与 sim/real 迁移能力。

## 要解决的问题

柔性制造/实验室工位：多品种小批量、人工分拣重复易错、专机无法适应来料变化。

## 核心闭环

来料 → 识别与位姿 → 抓取规划 → 无碰撞运动 → 分拣/上下料 → 结果确认 → 异常恢复 → 下一任务

## 为什么不是简单 Demo

| 维度 | 本项目 |
|------|--------|
| 场景 | 完整工作站（台、零件、料位、障碍、相机） |
| 任务 | 多阶段 + 多目标 + 异常恢复 |
| 架构 | 感知/规划/控制/任务/硬件抽象分层 |
| 迁移 | 上层接口稳定，只换驱动 |
| 验收 | 可量化成功率指标 |

## 技术栈

Ubuntu 22.04 · ROS2 Humble · MoveIt2 · Gazebo Classic · ros2_control · OpenCV · Python
