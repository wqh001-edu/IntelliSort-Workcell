# 10 · 实验与测试

## 指标定义

| 指标 | 定义 | 阈值 |
|------|------|------|
| 规划成功率 | 成功规划/请求 | ≥95% |
| 抓取成功率 | 成功夹持/尝试 | ≥85% |
| 任务完成率 | 成功任务/下发 | ≥85% |
| 异常恢复率 | 自动恢复/可恢复异常 | ≥70% |
| 节拍 | 单件端到端 | 12–25 s |

## 验收脚本（建议）

```bash
# 感知冒烟
ros2 topic echo /detections --once
ros2 topic echo /target_poses --once

# 任务
ros2 run intellisort_demo run_pick_demo
```

见 `tests/` 目录脚本。

## 异常注入

| 注入 | 期望 |
|------|------|
| 移走目标 | 低置信度/跳过 |
| 加障碍 | Replan |
| 夹爪失败 | 重试/跳过 |
| 超时 | Error 不假死 |
